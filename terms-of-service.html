2. Description of Service

MyLeadScout is a web application that enables users to find local business leads using the Google Places API and manage them through a built-in sales pipeline (CRM). The Service operates on a "Bring Your Own Key" (BYOK) model — users provide their own Google Maps API key to power searches.

Key features of the Service include:

  • Lead Finder — Search for businesses by type and location using Google Maps data, with real-time streaming results and multi-area scanning.
  • CSV Upload — Import your own business lists for qualification.
  • Export — Download leads as CSV or Excel files.
  • Sales Pipeline (CRM) — Qualify leads, track them through 8 deal stages, log activities (calls, emails, meetings), set follow-up reminders, and add tags.
  • Dashboard Analytics — View pipeline statistics, conversion rates, and follow-up reminders.
  • PDF Reports — Download one-page pipeline summary reports.
